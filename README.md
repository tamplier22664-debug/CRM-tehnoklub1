# CRM-tehnoklub1
Создана CRM-система для техноклуба на базе React, TypeScript и Tailwind CSS с интеграцией ИИ-агента через API и MCP. Система включает дашборд со статистикой, модули управления участниками, мероприятиями и проектами (с поддержкой Kanban), а также интерфейс чата с ИИ, панель инструментов MCP, логи запросов и настройки конфигурации сервера и ключей до
